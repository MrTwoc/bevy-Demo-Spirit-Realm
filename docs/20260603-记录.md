| 遍历 Compute Shader | `assets/shaders/svo_traversal.wgsl` | @workgroup_size(64) |

#### WGSL Bindings

| binding | 类型 | 用途 |
|---------|------|------|
| 0 | `storage read` | 节点缓冲区 (u64 × 2 per node) |
| 1 | `uniform` | 相机参数 (位置、渲染距离、视锥体) |
| 2 | `storage read_write` | 可见计数器 (atomic) |
| 3 | `storage read_write` | 可见节点 ID 列表 |

#### 核心 WGSL 函数

```wgsl
// 位置解码
fn decode_level(pos: u64) -> u32
fn decode_x(pos: u64) -> i32  // 带符号扩展
fn decode_y(pos: u64) -> i32
fn decode_z(pos: u64) -> i32

// 节点数据解码
fn get_node_type(data: u64) -> u32
fn get_child_existence(data: u64) -> u32
fn get_geometry_handle(data: u64) -> u32
fn get_child_ptr(data: u64) -> u32

// 剔除函数
fn test_plane(plane: vec4<f32>, center: vec3<f32>, half_size: f32) -> bool
fn is_visible(center: vec3<f32>, half_size: f32) -> bool  // LOD 0-1
fn is_visible_coarse(center: vec3<f32>, half_size: f32) -> bool  // LOD 2+
fn should_descend(lod_level: u32, distance: f32) -> bool

// 主遍历函数
@compute @workgroup_size(64, 1, 1)
fn main(@builtin(global_invocation_id) id: vec3<u32>)
```
