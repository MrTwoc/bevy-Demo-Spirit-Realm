# 2026-06-04

## SVO Section 生命周期修复

- `render_distance.rs`：插入节点前 `tracker.acquire(coord)` 保持 section 活跃，移除时用正确坐标 `tracker.release(coord.encode())`
- `node_manager.rs`：修复 `request_leaf_node` 中 `tracker.release()` key 不一致（使用 `coord.encode()` 代替 `pos`）
- `visibility_bridge.rs`：使用 `node_manager.node_count()` 代替 `node_data.len()` 检查节点数量
- 结果：active sections 从 0 → 106+，visibility_bridge 能正常工作

## 数据局部性优化（AoS 布局）

- `async_mesh.rs`：新增 `MeshVertex` 结构体（32 字节，repr(C)，position + normal + uv 交错）
- `SubMeshData` 改为 `Vec<MeshVertex>` 代替三个分离的 `Vec`
- 新增 `split_for_bevy()` 方法：仅在 GPU 上传时拆分为分离数组
- `lod.rs`：LOD 网格生成同步改为 AoS 布局

## 内存预分配优化

- `async_mesh.rs`：`estimate_vertex_capacity` 替换为 `count_visible_faces()`（两遍扫描）
- 第一遍精确统计可见面数（无内存分配），第二遍精确分配 AoS 顶点数组
- 消除过度预分配（旧估算可能多分配 50-200%）
- 移除未使用的 `generate_chunk_mesh_async` 函数

## 适配层

- `chunk_manager.rs`：两处 solid/water Mesh 上传路径改为先调用 `split_for_bevy()` 再 insert_attribute
