## Voxy 模组源码分析

阅读了本地 Voxy 模组源码（`项目参考/优化参考/voxy-dev/`），分析了其核心实现：

### Voxy 关键发现

1. **不合并 Chunk** — 每个 Section (32³) 独立生成 Mesh
2. **八叉树管理** — 使用 NodeStore 存储节点，每个节点 16 字节
3. **GPU 驱动遍历** — Compute Shader 进行层次遍历和剔除
4. **HiZ 遮挡剔除** — Hierarchical Z-Buffer 快速剔除不可见区域
5. **紧凑 Mesh 格式** — 每 quad 8 字节，减少 GPU 带宽

### 核心文件

- `NodeStore.java` — 节点存储管理
- `HierarchicalOcclusionTraverser.java` — GPU 遍历系统
- `RenderDataFactory.java` — Mesh 生成
- `traversal_dev.comp` — 遍历 Compute Shader

## Voxy 数据结构移植

将 Voxy 的 NodeStore 和 HierarchicalBitSet 移植到项目中：

### 新增文件

- `src/svo/hierarchical_bitset.rs` — 分层位集合，支持快速位分配
- `src/svo/node_store.rs` — 重写，使用 Voxy 的 4×u64 节点结构

### 修改文件

- `src/svo/mod.rs` — 更新位置编解码函数，使用 Voxy 的 rawPos 格式
- `src/svo/node_manager.rs` — 重写，适配新的 NodeStore API
- `src/svo/gpu_traversal.rs` — 更新 GpuNode 导入
- `src/svo/visibility_bridge.rs` — 更新 GpuNode 导入和解码函数

### 核心变化

1. **节点结构**：从 2×u64 (16字节) 改为 4×u64 (32字节)
2. **位置编码**：从 `(lvl:4)|(y:8)|(z:24)|(x:24)|(pad:4)` 改为 `(lvl:4)|(x:20)|(y:20)|(z:20)`
3. **分配器**：从简单 Vec 改为 HierarchicalBitSet
4. **API 风格**：从 Java 风格改为 Rust 风格
