# 2026-05-27 工作记录

## FPS 优化：shader + 编译配置改动

### 1. WGSL 着色器优化
- **文件**: `assets/shaders/voxel.wgsl`
- **改动**: `textureSample` → `textureSampleLevel`，显式 LOD=0
- **原因**: 避免 GPU 为每个 fragment 计算纹理 LOD 导数。Minecraft 风格纹理不使用 mipmap，level 恒为 0，无视觉差异
- **预期收益**: GPU fragment 阶段降低 5-10%

### 2. Release 编译配置优化
- **文件**: `Cargo.toml`
- **改动**: `opt-level = "s"`（体积优先）→ `opt-level = 3`（速度优先）
- **原因**: 面剔除、网格生成等 CPU 密集计算受益于速度优化
- **预期收益**: CPU 网格生成速度提升 5-15%

### 3. FPS 优化审计报告
- 完成了全代码库 FPS 优化审计，产出详细报告
- 核心发现：LOD0 固体方块未用 Greedy Meshing（最大瓶颈）、Draw Call 爆炸（1000+）、分帧工作分散
- 用户选择暂缓 Greedy Meshing 方案，先实施零风险快速改动
